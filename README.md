# החנוכיאדה המשפחתית הגדולה 🕎

משחק משפחתי בעברית מלאה ובכיווניות RTL, המיועד לאירוע חנוכה של כ-100 משתתפים.

## מה כבר בנוי

- מסך פתיחה בעברית המותאם לנייד.
- פתיחת חדר מנהל וקוד בן 6 ספרות.
- הצטרפות משתתפים באמצעות שם וקוד.
- חידון עם ארבע תשובות לכל שאלה.
- הוספת שאלות על ידי המנהל.
- מעבר בין שאלות בזמן אמת.
- חישוב ניקוד בצד השרת ומניעת מענה כפול.
- לוח מובילים שמתעדכן בזמן אמת.
- מפתח התשובות מופרד מהשאלות ואינו מוצג למשתתפים.

**המערכת עדיין אינה מוכנה לאירוע אמיתי ואינה פרוסה כמשחק פעיל.** בדיקת הבנייה האוטומטית ב-GitHub Actions עברה, אבל עדיין צריך להקים את מסד הנתונים, לחבר את משתני הסביבה, לבדוק משחק אמיתי משני טלפונים ולבצע בדיקות עומס.

## הקמה – שלב אחר שלב

### 1. חיבור מסד הנתונים הקיים (חשוב)
המשחק עודכן להשתמש בטבלאות נפרדות בשם `hanukkah_*`, כדי לא להתנגש בטבלאות הישנות שכבר קיימות בפרויקט שלך.
1. פתחו ב-Supabase את **SQL Editor**.
2. פתחו ב-GitHub את הקובץ `supabase/upgrade-existing-project.sql` והעתיקו את כולו.
3. הדביקו ב-SQL Editor ולחצו **Run** פעם אחת בלבד.
4. אם מופיעה שגיאה, עצרו ושלחו את הודעת השגיאה. אין למחוק טבלאות ישנות ואין לכבות RLS.

אם מדובר בפרויקט Supabase חדש וריק, אפשר להשתמש במקום זאת בקובץ `supabase/schema-v2-secure.sql`.

### 2. הפעלת כניסה אנונימית
ב-Supabase פתחו **Authentication → Sign In / Providers** והפעילו **Anonymous Sign-ins**. המשחק משתמש בזה כדי לזהות כל מכשיר בלי לבקש מהמשפחה לפתוח חשבון.

### 3. הגדרת כתובת ומפתח ציבורי
ב-Supabase פתחו **Project Settings → API** והעתיקו:
- Project URL
- anon / publishable key

אל תשתפו ואל תכניסו בשום מקום את `service_role` או Secret key.

### 4. הפעלה מקומית
1. התקינו Node.js.
2. הריצו `npm install`.
3. העתיקו את `.env.example` לקובץ `.env.local`.
4. הכניסו את כתובת הפרויקט ואת המפתח הציבורי למשתנים `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`.
5. הריצו `npm run dev`.

### 5. פריסה ב-Vercel
ייבאו את המאגר ל-Vercel, הגדירו באפשרות **Environment Variables** את אותם שני משתנים ציבוריים, ואז בצעו Deploy. אחרי כל עדכון ב-GitHub תתבצע פריסה אוטומטית אם חיבור Git הוגדר.

## אבטחה ומגבלות

- אין להכניס למאגר או לדפדפן מפתח `service_role`.
- סכימת v2 משתמשת ב-RLS ובפעולות RPC מאומתות.
- `supabase/schema.sql` היא סכימה מוקדמת בלבד; לפרויקט חדש יש להשתמש ב-`supabase/schema-v2-secure.sql`.
- אין עדיין בדיקת עומס ל-100 משתתפים. לפני האירוע יש לבדוק כמה מכשירים במקביל, חיבור מחדש, מעבר בין שאלות וניקוד.
