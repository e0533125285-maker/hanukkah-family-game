# החנוכיאדה המשפחתית הגדולה 🕎

אפליקציית משחקים משפחתית בעברית מלאה ובכיווניות RTL, המתוכננת לאירוע חנוכה חד-יומי של כ-100 משתתפים.

## מצב הפיתוח

המאגר מכיל כרגע ממשק React ראשוני ותשתית נתונים בשלבי פיתוח. **המערכת עדיין אינה מוכנה לאירוע אמיתי ואינה פרוסה כמשחק פעיל.** מסכי הממשק הקיימים הם אבטיפוס: עדיין לא הושלם החיבור שלהם למודל האבטחה החדש, ולא נבדקה השתתפות של 100 משתמשים.

## קבצים חשובים

- `src/main.jsx` ו-`src/style.css` – ממשק המשתמש הראשוני.
- `supabase/schema.sql` – סכימה מוקדמת בלבד; אינה מאובטחת לשימוש ציבורי.
- `supabase/schema-v2-secure.sql` – בסיס נתונים מתקדם עם משתמשים מאומתים, בעלות מנהל על חדר, משתתפים, שאלות, תשובות וחישוב ניקוד בצד השרת.

## הקמה מקומית (למפתחים)

1. התקינו Node.js.
2. הריצו `npm install`.
3. הגדירו בפרויקט Supabase את משתני הסביבה שמופיעים ב-`.env.example`.
4. הריצו `npm run dev`.

## Supabase ואבטחה

לפני חיבור לקהל יש להקים פרויקט Supabase חדש/נקי ולהחיל עליו את `supabase/schema-v2-secure.sql` דרך SQL Editor. הסכימה החדשה מניחה שימוש ב-Supabase Auth (כולל התחברות אנונימית למשתתפים), מגבילה פעולות מנהל לבעל החדר, ומחשבת תשובות וניקוד בפונקציה בצד מסד הנתונים כדי למנוע ניקוד כפול.

**חשוב:** הממשק הנוכחי עדיין אינו מממש את זרימת האימות ואת קריאות ה-RPC של הסכימה החדשה. אין להפעיל אותו מול נתונים אמיתיים לפני השלמת ההתאמה. אין להכניס למאגר או לדפדפן מפתח `service_role`; בדפדפן מותר להשתמש רק במפתח publishable/anon המתאים ובמדיניות RLS תקינה.

הקובץ `supabase/schema.sql` הוא גרסה מוקדמת ולא מומלץ להחיל אותו בפרויקט חדש. הוא נשמר לצורכי תיעוד בלבד.

## פריסה

היישום מיועד לפריסה ב-Vercel כיישום Vite. פריסה אינה מעידה כשלעצמה שהמשחק מוכן: לפני אירוע נדרשים השלמת חיבור הממשק לסכימה המאובטחת, בדיקות הרשאות, בדיקות מובייל, בדיקות חיבור מחדש ובדיקת עומס מדורגת.
