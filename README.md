# החנוכיאדה המשפחתית הגדולה 🕎

אפליקציית משחקים משפחתית בעברית מלאה ובכיווניות RTL, המיועדת לאירוע חנוכה חד-יומי של כ-100 משתתפים.

## הפעלה מקומית
1. התקינו Node.js.
2. הריצו `npm install`.
3. העתיקו את `.env.example` אל `.env.local` והגדירו פרטי Supabase.
4. הריצו `npm run dev`.

## תשתית בזמן אמת
הפרויקט משתמש ב-Supabase (Postgres + Realtime). יש להגדיר פרויקט Supabase ולהחיל את `supabase/schema.sql`.
ללא הגדרות Supabase האפליקציה מציגה מצב תצוגה מקומית בלבד; אין להציג אותו כאירוע מרובה-משתתפים פעיל.

## פריסה
מיועד לפריסה ב-Vercel כיישום Vite. יש להגדיר ב-Vercel את משתני הסביבה שמופיעים ב-`.env.example`.

## מצב
גרסת בסיס ראשונית: מסך כניסה, מסך מארח, חידון ומבנה חיבור ל-Realtime. לפני שימוש באירוע אמיתי יש להשלים אימות והרשאות מנהל, בדיקות עומס ואבטחת מידע.
